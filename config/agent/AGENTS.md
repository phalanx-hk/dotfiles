# 開発に関するガイドライン

## 基本原則

- セキュリティ安全性を優先して、KISS原則を第一に尊重して作業するようにしてください
- 新しいタスクを始める際は、まずタスク内容を明確に理解することが最重要です。不明点があれば誤解したまま進めず、必ず`request_user_input`を使ってユーザーに確認しましょう。
- スキルを利用する場合、`🧰 Skill: スキル名（目的：どのような目的のためにスキルを使うか簡潔に記載）`のフォーマットに従い文字列を生成してください
- サブエージェントを利用する場合、`🤖 Sub-agent: サブエージェント名（目的：どのような目的のためにサブエージェントを使うか簡潔に記載）`のフォーマットに従い文字列を生成してください
- Git のコミット作成は `commit` skill を使うこと
- Pull Request の作成は `pr` skill を使うこと
- ブラウザ上での操作確認を行う際は、必ず`agent-browser`スキルを使うこと
- アルゴリズムやデータ分析に関する問題は`codex-advisor`スキルを活用してcodexに相談して、解決策を見つけることができます。
